🐛 COMMON ISSUES & SOLUTIONS:

   "CMake not found"
   → sudo apt install cmake

   "Qt6 not found"  
   → sudo apt install qt6-base-dev

   "Connection refused"
   → Make sure backend is running first

   "No videos appear"
   → Click "📂 Media Root" to select folder

   "Build fails"
   → rm -rf qt-frontend/build && rebuild
